## 🚨 Critical Missing Applications

### High Priority (Affect Accuracy)

1. **Battery max discharge current** (`maxDischargeA`)
   - **Impact:** Could allow unsafe discharge rates
   - **Fix:** Add current limiting in simulation

2. **Solar cloudy day factor** (`cloudyDayFactor`)
   - **Impact:** Doesn't simulate worst-case cloudy conditions
   - **Fix:** Apply factor during cloudy day simulation

3. **Solar worst case cloudy days** (`worstCaseCloudyDays`)
   - **Impact:** Doesn't simulate extended cloudy periods
   - **Fix:** Extend simulation with cloudy days

4. **Battery discharge efficiency** (`batteryDischargeEfficiencyPct`)
   - **Impact:** Doesn't account for discharge losses
   - **Fix:** Apply efficiency factor during discharge

5. **Simulation reserve %** (`reservePct`)
   - **Impact:** Doesn't maintain reserve capacity
   - **Fix:** Apply reserve to minimum SoC

### Medium Priority (Affect Warnings/Sizing)

6. **Inverter max total charge current** (`maxTotalChargeA`)
   - **Impact:** Could overcharge battery
   - **Fix:** Limit total charge from grid + solar

7. **MPPT voltage/current limits**
   - **Impact:** Could damage MPPT
   - **Fix:** Enforce limits in simulation

8. **Panel current specs** (Isc, Imp)
   - **Impact:** Inaccurate current calculations
   - **Fix:** Use in current calculations

### Low Priority (Display/Planning Only)

9. **Load priority shedding**
   - **Impact:** No automatic load shedding
   - **Fix:** Implement priority-based shedding

10. **Load room/zone assignment**
    - **Impact:** No zone-based analysis
    - **Fix:** Add zone-based calculations
